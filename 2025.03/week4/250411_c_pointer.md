## 포인터란?

포인터는 **"주소값을 저장하는 변수"** 이다.
즉, 어떤 데이터가 메모리 어딘가에 저장되어 있을 텐데, 포인터는 그 **"메모리 주소"** 를 기억하는 변수​.

### 왜 포인터가 필요할까?

- 변수는 데이터를 저장하지만, 포인터는 그 변수의 주소를 저장한다.
- 포인터를 통해 간접적으로 데이터를 읽거나 수정할 수 있다.
- 함수 간 데이터 전달, 배열 처리, 동적 메모리 할당 등에서 아주 유용하게 사용된다.

### 기본 문법

```c
int a = 10;
int *p;   // int형 변수를 가리키는 포인터 선언
p = &a;   // a의 주소를 p에 저장

printf("%d\n", *p); // *p는 a의 값을 출력 (10)
```

- `*p`는 **"포인터 p가 가리키는 주소에 저장된 값"** 을 의미한다.
- `&a`는 변수 `a`의 주소를 의미한다​.

### 포인터는 변수다!

```c
int a, b;
int *p;
p = &a;
*p = 2;   // a = 2 와 동일한 의미
p = &b;
*p = 4;   // b = 4 와 동일한 의미
```

즉, 포인터도 값을 바꿀 수 있고, 다른 변수를 가리키도록 할 수도 있다.

### 포인터에 타입이 왜 필요할까?

포인터도 형이 필요하다.
예를 들어, `int *p`는 int형 변수를 가리키는 포인터고, `char *p`는 char형 변수를 가리킨다.

왜냐하면, 포인터가 어떤 타입의 데이터를 가리키는지 알아야 **얼마만큼의 메모리를 읽을지** 결정할 수 있기 때문

## 심화

### 이중 포인터 개념

이중 포인터는 포인터를 가리키는 **포인터** 이다. 즉, `int *p;`는 `int`형 변수의 주소를 저장하는 포인터고,
`int **pp;`는 포인터 **p의 주소를 저장하는 포인터**이다.

```c
int a = 10;
int *p = &a;    // a를 가리킴
int **pp = &p;  // p를 가리킴
```

```
a    : 10     (실제 값)
p    : 주소(&a) -> 가리키는 값은 10
pp   : 주소(&p) -> 가리키는 값은 주소(&a)
```

#### 예시 코드

```c
#include <stdio.h>

int main() {
    int a = 5;
    int *p = &a;
    int **pp = &p;

    printf("a = %d\n", a);          // 5
    printf("*p = %d\n", *p);        // 5
    printf("**pp = %d\n", **pp);    // 5

    **pp = 20;
    printf("a = %d\n", a);          // 20 (이중 포인터를 통해 값 변경)
    return 0;
}

```

### 왜 이중 포인터를 쓸까?

1. 함수 안에서 포인터 자체를 변경하고 싶을 때

2. 다차원 배열이나 포인터 배열을 다룰 때

3. 문자열 배열이나 동적 메모리 할당에서 유용

### 예시 : 함수에서 포인터를 바꾸고 싶을 때

```c
#include <stdio.h>

void changePointer(int **pp) {
    static int b = 99;
    *pp = &b;
}

int main() {
    int a = 10;
    int *p = &a;

    changePointer(&p);  // p 자체의 주소를 넘김
    printf("*p = %d\n", *p);  // 99
    return 0;
}
```

👉 만약 단순히 p만 넘기면 함수 내부에서만 바뀌고 원래 포인터는 변하지 않는다. 그래서 이중 포인터가 필요한 것이다.


## 실습 퀴즈

#### 1. 아래 코드에서 출력 결과는?

```c
int a = 5;
int *p = &a;
*p = 10;
printf("%d\n", a);
```

- 정답 : 10

`*p` 는 포인터 변수이고 `&a`는 `a`변수의 주소값을 포인터 변수 `p`에 대입한다는 것이다.

`*p` 에 10을 전달하면 포인터 변수 내부에 있던 `a`의 주소값을 이용해 `a`의 값을 10으로 바꾸는 것이다.

#### 2. 다음 코드를 작성하고, `a`, `b`, `*p`의 값을 각각 출력하라.

```c
#include <stdio.h>

int main() {
    int a = 10;
    int b = 20;
    int *p;

    p = &a;
    *p = *p + 5;

    p = &b;
    *p = *p + 10;

    printf("a = %d\n", a);
    printf("b = %d\n", b);
    printf("*p = %d\n", *p);

    return 0;
}
```

```
a = 15
b = 30
*p = 30
```

`*p = *p + 5`는 `a`의 값에 5를 더한 것이다.

그다음 `p`가 `b`를 가리키고 있으니 `b`에 10을 더한 것이다.

#### 3. 아래 코드의 출력 결과를 예상하라.

```c
#include <stdio.h>

int main() {
    int nums[3] = {100, 200, 300};
    int *p = nums;

    for(int i = 0; i < 3; i++) {
        printf("%d ", *(p + i));
    }

    return 0;
}
```

- 정답 : 100 200 300

배열 이름 `nums`는 배열의 첫 번째 요소의 주소와 같다.

`*(p + i)`는 포인터 연산을 이용한 배열 접근이다.

#### 4. 다음 코드를 실행하면 어떤 결과가 나오는가?

```c
#include <stdio.h>

int main() {
    int a = 42;
    int *p = &a;
    int **pp = &p;

    **pp = **pp + 8;

    printf("a = %d\n", a);
    return 0;
}
```

- 정답 : a = 50

``**pp``는 `p`가 가리키는 주소를 통해 `a`에 접근하는 것

`**pp = **pp + 8`은 결국 `a = a + 8`과 같음

#### 5. 다음 코드에서 어떤 문장이 출력되는가?

```c
#include <stdio.h>

int main() {
    char *str = "Hello, World!";
    printf("%c\n", *(str + 7));
    return 0;
}
```

- 정답 : W

`str`은 문자열의 시작 주소를 가리키는 포인터

`*(str + 7)`은 7번째 문자 `'W'`를 가리킴 (0부터 시작)

#### 6. malloc을 이용해서 사용자가 입력한 숫자만큼 정수를 저장하고, 합을 구하는 프로그램을 작성하라.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    printf("입력할 숫자의 개수를 입력하세요: ");
    scanf("%d", &n);

    int *arr = (int*)malloc(n * sizeof(int));
    if (arr == NULL) {
        printf("메모리 할당 실패\n");
        return 1;
    }

    printf("숫자 %d개를 입력하세요:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i];
    }

    printf("총합: %d\n", sum);

    free(arr); // 꼭 메모리 해제!
    return 0;
}
```

`malloc()`은 힙(heap)에 메모리를 할당한다.

사용 후에는 반드시 `free()`로 해제해야 한다.
