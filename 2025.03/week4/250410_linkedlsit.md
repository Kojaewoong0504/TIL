### 링크드 리스트란?

링크드 리스트(Linked List)는 자료구조 중 하나로, 데이터를 순차적으로 저장하면서 각 원소가 다음 원소를 가리키는 방식으로 연결된 리스트이다. 배열과는 다르게 연속된 메모리 공간에 저장되지 않고, 각 요소가 포인터(또는 참조)를 통해 연결된다.

링크드 리스트는 **노드(Node)** 라는 단위로 구성된다.
각 노드는 보통 다음 두 가지를 포함한다:

1. 데이터(Data): 저장할 실제 값

2. 포인터(Next): 다음 노드를 가리키는 참조(주소)

```css
[1 | ●] → [2 | ●] → [3 | null]
```

🔹 링크드 리스트의 종류

- 단일 연결 리스트(Singly Linked List)
각 노드가 오직 다음 노드만 가리킴

- 이중 연결 리스트(Doubly Linked List)
각 노드가 이전 노드와 다음 노드 모두를 가리킴

- 원형 연결 리스트(Circular Linked List)
마지막 노드가 처음 노드를 가리킴, 끝이 없음

🔹 꼭 알아야 할 개념들

|개념	|설명|
|-|-|
|노드(Node)|	데이터와 다음 노드에 대한 참조를 가진 기본 단위|
|헤드(Head)	|리스트의 첫 번째 노드|
|포인터(Reference)	|다음 노드를 가리키는 변수|
|삽입/삭제|	중간에 노드를 추가하거나 제거할 수 있음 (배열보다 효율적)|
|순회(Traversal)|	처음부터 끝까지 차례로 노드를 따라가며 처리|
|Null 체크|	마지막 노드의 다음은 null 또는 None임|

🔹 구현할 때 중요 포인트

1. 노드 클래스를 만들기
    - data, next 필드를 가지는 클래스

2. 리스트 클래스 만들기
    - head, insert, delete, search, print 등의 메서드 구현

3. 엣지 케이스 처리
    - 빈 리스트, 맨 앞/뒤에서 삽입·삭제, 없는 값 처리 등

### C로 구현하기

```c
int insertSortedLL(LinkedList *ll, int item)
{
	ListNode *newNode, *cur, *prev; // 새로운 노드, 현재 노드, 이전 노드를 저장할 ListNode 구조체 타입 선언

	// 새 노드 생성
	newNode = (ListNode *)malloc(sizeof(ListNode));
	if (newNode == NULL) return -1;
	newNode->item = item;
	newNode->next = NULL;

	// 빈 리스트이거나 맨 앞에 삽입할 경우
	if (ll->head == NULL || item <= ll ->head->item) {
		newNode->next = ll->head;
		ll->head = newNode;
		ll->size++;
		return 0;
	}

	prev = ll->head;
	cur = ll->head->next;

	while (cur != NULL && cur->item < item) {
		prev = cur;
		cur = cur->next;
	}

	newNode->next = cur;
	prev->next = newNode;
	ll->size++;
	return 0;
}
```

## 구현 목표

정글에서 제공해준 과제 리스트? 에 있는 Q1_A_LL은 insertSortedLL을 구현해야 하는 과제다. 이 insertSortedLL은 링크드 리스트에 입력되는 값이 정렬이 되어 입력이 되어야 한다.

### 구현 코드 설명

1. malloc을 이용해 새로운 노드를 생성하고 있다.
    - 리스트 크기가 실행 중에 정해지기 때문
    - 연결 리스트는 크기가 고정된 배열이 아님.
    - 프로그램이 실행되면서 사용자의 입력이나 다른 조건에 따라 노드 개수가 유동적으로 바뀜.

2. ll이 빈 리스트거나 맨 앞에 삽입할 경우 즉 현재 입력된 값이 일력한 값이 리스트의 맨 앞에 들어가야 하는 경우 처리 되는 코드이다.

    - 새로운 노드의 다음 노드를 현재 가장 앞의 노드로 설정한다.
    - 링크드리스트의 가장 앞 노드 정보를 새로 만든 노드로 설정한다.
    - 링크드리스트의 크기를 1 증가시킨다.

    **이 조건문일 실행되면 반환을 하고 아래의 코드는 실행되지 않는다.**

3. 이전, 다음 노드를 설정한다.

4. 리스트를 앞에서부터 순회하면서, item보다 작은 값이 있는 노드들을 건너뜀
    - 즉, item이 들어가야 할 적절한 위치를 찾는 과정이다.
    - 순회는 cur 포인터로 하고, prev는 바로 앞 노드를 기억해 둠.

5. 새 노드가 자리잡을 위치를 발견하면 다음 노드 정보를 새 노드에 저장하고 이전 노드의 다음 값을 새 노드로 연결해 이전 노드에서 새로운 노드로 새로운 노드는 다음 노드 정보를 연결한다.

6. 링크드 리스트의 크기를 1 증가한다.
